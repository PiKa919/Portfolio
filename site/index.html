decisions that shape the implementation

The useful questions are often around the model. Who owns a job? Which version produced a result? What evidence supports a decision?

Document inference with release gates

ForgeSight
page upload→durable ledger→isolated runtime→detections→frozen evaluation→release decision

Separate runtime processes keep memory measurements interpretable. Leases and fencing prevent an expired worker from writing stale results. The memory calibration rejected its own linear fit when measured RSS contradicted the assumption.

Evidence before generation

MP-KG-RAG
documents→source hashes→graph retrieval→frozen evidence→five perspectives→cited synthesis

All perspectives analyze the same evidence set. Schema repair, checkpoint identity, and per-row quarantine make failures inspectable. Evidence-ID membership is recorded separately from semantic support.

Inventory-to-GL workbench
exports→health gates→normalized balances→evidenced bridges→residual review→evidence packet

Integer minor-unit money and immutable source versions support deterministic reconciliation. Reviewer decisions and audit events persist. The public demonstration uses synthetic data and keeps the ERP boundary read-only.

model blocks→ONNX subgraphs→CPU / NNAPI→reusable buffers→timing and RSS

Research & evidence

what a result can tell us

A completed research archive

MP-KG-RAG includes four variants with 1,550 final rows each and 7,750 perspective records. The archive supports reproducibility and failure analysis. It does not establish uniformly better semantic answer quality.

A fixed evaluation set

TerraServe's archived MobileNetV3-Small predictions contain 202 correct classifications out of 210 supplied evaluation tiles. That is a fixed-set result. Geographic independence and generalization remain unestablished.

A memory model that failed

ForgeSight's assumed linear peak-RSS fit produced an invalid negative intercept. Calibration now reports the fit as invalid and falls back to the largest measured peak, with the finding recorded in an architecture decision.

Competition and notebook practice

The October 4 Kaggle audit recorded eight completed competitions and public experiments across OCR, speech, CryoET, RNA, remote sensing, and applied prediction. Private drafts and linked work are not counted as independently authored publications.
