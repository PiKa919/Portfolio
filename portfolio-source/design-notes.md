# Engineering portfolio plan

Approved 13 October 2026: retain the OpenCode dark editorial template, expand it to a full engineering portfolio, and publish publicly.

Architecture: buildless semantic HTML, CSS, and small browser JavaScript. A Python generator reads a curated public project ledger. All copy is available without JavaScript; JavaScript adds archive search and category filters. No accounts, tracking, private datasets, contact details, or secrets.

1. Prepare a curated ledger from the current aboutme.md and newer project READMEs. Preserve employment dates, prototype labels, attribution, and metric scope. Do not publish the source career profile itself.
2. Adapt the requested template with real identity, experience, six selected projects, system walkthroughs, evidence notes, learning areas, searchable archive, and verified profile links. Retain serif/mono typography, dark tokens, and annotated figures. Use existing ForgeSight imagery.
3. Validate generated HTML, local anchors, placeholder removal, archive filters, mobile overflow, keyboard access, and browser rendering. Keep the page usable without JavaScript and honor reduced motion.
4. Package the exact pushed source using Sites workflow, publish publicly, confirm terminal deployment status, and open the deployed page.

Evidence limits: the October 4 inventory is a dated snapshot. Newer READMEs establish implementation descriptions, not fresh benchmark reproduction. Q-Forge is a subgraph experiment. MP-KG-RAG metrics are not semantic quality. Reconciliation is a synthetic pre-sales demonstration. AiRA is a simulated workout prototype. Forks are not original projects. Exclude unbuilt concepts and unaudited empty folders.
